# MusicRepeat ☕

**カフェBGMプレイヤー** — フォルダーを指定するだけで、中の音楽を自動で音質調整し、**止めるまで流し続ける**Windows向けデスクトップアプリ。

「店舗向け」と「個人向け」の両方のシーンで使えるよう、機能は2つの軸で整理されています。

---

## 📥 ダウンロード

最新版は [**Releases ページ**](https://github.com/miyazk-dev/musicrepeat/releases/latest) から取得できます。

| ファイル | 用途 |
|---|---|
| `MusicRepeat-Setup-x.x.x.exe` | インストーラー版(おすすめ) |
| `MusicRepeat x.x.x.exe` | ポータブル版(インストール不要・USBメモリでも使える) |

> ※ コード署名なしのため、初回起動時に Windows Defender SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動してください。
> ※ 新しいバージョンを公開するにはタグ `vX.Y.Z` をプッシュしてください(GitHub Actionsが自動でビルド&リリースします: `.github/workflows/release.yml`)

## 🏪 店舗向け — 「一日中安心して放置できる」

| 機能 | 説明 |
|---|---|
| 📱 **スマホリモコン** | 同じWi-FiのスマホからQRコードで接続。再生/音量/プリセット/曲選択/スリープを遠隔操作(WebSocketでリアルタイム同期)。**PWA対応**なのでスマホのホーム画面からアプリのように起動可能 |
| ⏰ **時間帯オートプリセット** | モーニング(7-11 → クリア)/カフェタイム(11-18 → カフェ)/ナイト(18-7 → リラックス+0.95x)を自動切替。スケジュールは自由に編集可・日またぎ対応 |
| 🔊 **出力先管理** | 出力デバイス一覧・ワンクリック切替。Windows Bluetooth設定へ直行ボタン |
| 🅱 **Bluetooth自動連携** | スピーカー切断時にフェードアウトして自動一時停止(大音量事故防止)。登録デバイス接続時に自動出力切替&再生(各ON/OFF可) |
| 🛡 **エラータフネス** | 3段階フォールバック(通常 → 内部デコード → 内蔵FFmpeg変換)で再生が止まらない。失敗時は原因を表示して次曲へ継続 |
| 🖥 **常時安定の画面** | 全画面モード(操作しないとUIが隠れる)/常に最前面/ステータスバー/ビジュアライザー |

## ☕ 個人向け — 「自分だけの心地よい空間」

| 機能 | 説明 |
|---|---|
| 🌧 **環境音ミキサー** | 雨/焚き火/カフェのざわめき(リアルタイム合成)や自分のファイルをBGMの裏でブレンド。「環境音の量」スライダーで調整 |
| 🎚 **音質の自動調整** | ☕カフェ/🌿リラックス/✨クリア プリセット+「落ち着かせる」微調整。**AGC**(曲ごとの音量差を自動ならす) |
| 🎛 **細かい音作り** | 3バンドEQ/リバーブ/ステレオパン/モノラル/曲末フェード/再生速度0.5x〜2x(ピッチ保持) |
| 🎵 **再生の自由** | 無限連続再生/シャッフル/リピート/「次に再生」キュー/並び替え(名前・更新日・シャッフル)/スリープタイマー |
| 👆 **長押しメニュー** | 再生ボタン・停止ボタン・モードピル・曲リストを0.5秒長押しで詳細操作が出る |

## 📲 スマホリモコンの使い方(PWA)

1. PC側アプリの「📱 リモコン」チップ → 「サーバーを開始」
2. 表示された **QRコードをスマホで読み取る**(URL例: `http://192.168.1.x:8080`)
3. スマホのブラウザでリモコン画面が出たら、メニューの「**ホーム画面に追加**」を選ぶ
   - Android: Chrome の ⋮ → ホーム画面に追加
   - iPhone: Safari の共有ボタン → ホーム画面に追加
4. 以後はホーム画面のアイコンからフルスクリーンのアプリとして起動できます

> 2回目以降はアプリシェルがキャッシュされ、PC側が再起動中でも画面が出ます(曲リスト・操作はPC起動後に再接続)。

## ⌨ キーボードショートカット

| 操作 | キー |
|---|---|
| 再生 / 一時停止 | `Space` |
| 5秒戻る / 進む | `←` / `→` |
| 前の曲 / 次の曲 | `Shift`+`←` / `Shift`+`→` |
| 音量 | `↑` / `↓` |
| 全画面 | `F` または `F11`(`Esc`で解除) |
| フォルダーを開く | `Ctrl+O` |
| 常に最前面 | `Ctrl+T` |
| 上級者向けパネル | `Ctrl+,` |
| シャッフル / リピート / モノラル | `S` / `R` / `M` |
| ショートカット一覧 | `?` |
| 閉じる/解除 | `Esc` |

## 対応形式

mp3 / wav / ogg / oga / flac / m4a / aac / opus / webm
(拡張子と中身が違うファイルは内蔵FFmpegが自動変換して再生します)

## 使い方

1. アプリを起動
2. 「フォルダーを開く」(またはフォルダーを窓にドラッグ)
3. すぐに再生開始 — 以後、停止するまで流れ続けます
4. 前回のフォルダー・設定・音量は自動で記憶されます

## ファイル / ビルド

```
dist2\win-unpacked\MusicRepeat.exe        ← 起動が一番速い(おすすめ)
dist2\MusicRepeat-Setup-x.x.x.exe         ← インストーラー版
dist2\MusicRepeat x.x.x.exe               ← ポータブル版
```

開発:
```
npm install
npm start        # 開発起動
npm run dist     # .exe 再ビルド
node scripts/gen-icons.js   # PWAアイコン再生成
```

技術スタック: Electron + Web Audio API + 内蔵FFmpeg(変換用) + ws/qrcode(リモコン・PWA)
更新履歴は `RELEASE_NOTES.md`、またはアプリ内「ヘルプ → リリースノート」。
